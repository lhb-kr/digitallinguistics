PBL Module 2 · Methodology Section

Classification Formula

How Shakespeare's plays are scored, shaped, and typed

Overview

Two-Axis Classification Framework

Each play is assigned a type along two independent dimensions — its Emotional Profile (how sentiment moves through the arc of the work) and its Relational Profile (how characters are connected and distributed). The combination of these two dimensions, with an optional third indicator, determines cluster membership.

Emotional Profile

  • Arc shape shorthand (↗ ↘ V ∧ ~ →)
  • Mean sentiment polarity $\bar{s}$
  • Volatility $\sigma_s$
  • Midline crossing count $C_0$
  • Start / end scores

Relational Profile

  • Network density $D$
  • Community count $K$
  • Bridge character score $B$
  • Optional: protagonist-chaos indicator $\delta$

Stage 1

Raw Sentiment Scoring

Each speech unit $i$ in a play is passed through two independent sentiment models. Both return a score on the interval $[-1, 1]$, where $-1$ is maximally negative and $+1$ is maximally positive.

VADER Score

$$s_i^{V} \in [-1,\, 1]$$

VADER produces a compound score by combining positive, negative, and neutral sub-scores with rule-based adjustments for punctuation and capitalisation. It is applied directly to each speech unit.

Deep Learning Score (siebert)

The siebert model outputs a binary label (POSITIVE / NEGATIVE) with a confidence probability $p \in [0, 1]$. This is mapped onto the signed scale:

$$s_i^{DL} = \begin{cases} +p & \text{if label} = \text{POSITIVE} \\ -p & \text{if label} = \text{NEGATIVE} \end{cases}$$

Stage 2

Smoothing

Raw per-unit scores are highly noisy. Smoothing reveals the underlying emotional arc. Two methods are available; the method and window size used for final classification must be stated explicitly.

LOWESS (default)

Locally Weighted Scatterplot Smoothing fits a weighted regression at each point, using a tricube kernel over a neighbourhood of width $h$ (the Window slider):

$$\hat{s}(x) = \sum_{i=1}^{n} w_i(x)\, s_i, \qquad w_i(x) \propto K\!\left(\frac{x - x_i}{h}\right)$$

LOWESS emphasises large-scale trends and is less affected by single extreme values. It is the recommended method for arc shape classification.

Moving Average

A simple rolling mean over a window of $w$ consecutive units:

$$\hat{s}_i = \frac{1}{w} \sum_{j=i}^{i+w-1} s_j$$

⚑ Methodological note

The granularity setting (sentence / line–speech / scene) and the window size both affect all downstream statistics. The values used for final analysis must be reported in the methodology section so that results are reproducible.

Stage 3

Arc-Level Statistics

Let $\hat{s}_1, \hat{s}_2, \ldots, \hat{s}_n$ denote the smoothed score sequence for a play of $n$ speech units. The following statistics are computed and exported via the dashboard's Download All Summary CSV function.

Feature Formula What it captures
Start score $\hat{s}_1$ Opening emotional register
End score $\hat{s}_n$ Closing emotional register
Mean sentiment $\bar{s} = \dfrac{1}{n}\displaystyle\sum_{i=1}^{n} \hat{s}_i$ Overall tonal polarity
High $\max_i\, \hat{s}_i$ Peak positive moment
Low $\min_i\, \hat{s}_i$ Peak negative moment
Volatility $\sigma_s = \sqrt{\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}(\hat{s}_i - \bar{s})^2}$ Emotional turbulence
Arc direction $\Delta = \hat{s}_n - \hat{s}_1$ Overall rise or fall
Midline crossings $C_0 = \#\{\,i : \hat{s}_i \cdot \hat{s}_{i+1} < 0\,\}$ Tonal reversals (see rule below)

⚑ Crossing count rule (team-defined)

A crossing is counted only when the smoothed arc stays on the opposite side of zero for at least one full act. Brief dips across the midline within a single act are excluded. This rule must be applied consistently across all 37 plays.

Stage 4

Arc Shape Classification

Each play is assigned a shape shorthand using the arc-level statistics. The function is:

$$\text{Shape}(p) = f\!\left(\hat{s}_1,\; \hat{s}_n,\; \bar{s},\; \sigma_s,\; C_0\right)$$
↗ Rising
↘ Falling
V Valley
∧ Peak
~ Oscillating
→ Flat
Shape Condition
↗ Rising $\hat{s}_n - \hat{s}_1 > \theta$ and $C_0 \leq 1$
↘ Falling $\hat{s}_1 - \hat{s}_n > \theta$ and $C_0 \leq 1$
V Valley $\bar{s} < \hat{s}_1$ and $\bar{s} < \hat{s}_n$
∧ Peak $\bar{s} > \hat{s}_1$ and $\bar{s} > \hat{s}_n$
~ Oscillating $C_0 \geq 2$
→ Flat $\sigma_s < \varepsilon$

The thresholds $\theta$ (direction sensitivity) and $\varepsilon$ (flatness tolerance) are set by the team before classification. Their chosen values must appear in the final report to make results replicable.

Stage 5

Composite Classification

The final type of play $p$ is a function of both profiles together:

$$\text{Type}(p) = f\!\Bigl(\;\underbrace{\text{Shape}(p),\;\bar{s}(p),\;\sigma_s(p)}_{\text{Emotional Profile}},\quad\underbrace{D(p),\;K(p),\;B(p)}_{\text{Relational Profile}}\;\Bigr)$$

Where the Relational Profile variables, derived from Gephi / DraCor, are:

Symbol Meaning Source
$D(p)$ Network density of play $p$ Gephi / DraCor
$K(p)$ Number of detected communities (modularity clusters) Gephi modularity
$B(p)$ Betweenness centrality of the highest-ranked character Gephi / NetworkX

Stage 6 · Optional Third Dimension

Protagonist-Chaos Indicator

A binary indicator that tests whether the character who bridges the network is also the most emotionally volatile speaker. Where this is true, the play centres chaos on a single protagonist; where false, sentiment is distributed across an ensemble.

$$\delta(p) = \mathbf{1}\!\left[\;\underset{c}{\arg\max}\;\text{Betweenness}(c) \;=\; \underset{c}{\arg\max}\;\sigma_s(c)\;\right]$$
Value Interpretation Example
$\delta = 1$ Bridge character = most volatile speaker → protagonist-centred Hamlet, King Lear
$\delta = 0$ Separate characters → distributed ensemble sentiment A Midsummer Night's Dream, Much Ado

Methodological Limitations

What to Acknowledge in the Report

1 · Language mismatch

Neither VADER nor siebert was trained on Early Modern English. Archaic negation ("I am not merry"), false friends ("passion," "awful"), and intensifiers ("passing strange") are parsed incorrectly. Using both models and cross-checking agreement partially mitigates this, but results should not be treated as ground truth from either model alone.

2 · Threshold dependency

Arc shape assignments depend on the chosen values of $\theta$ and $\varepsilon$. Different threshold choices can change a play's shape classification. The report must state which values were used and why.

3 · Granularity sensitivity

All arc statistics — mean, high, low, crossing count — change with granularity setting (sentence / line–speech / scene). The setting used for final analysis must be fixed and documented before results are compared across plays.

4 · Combination rule not yet defined

The formula above combines the Emotional Profile and Relational Profile vectors, but the distance metric or decision rule that maps the combination to a cluster label has not yet been specified. This is an open methodological step. Options include Euclidean distance to centroid, k-means clustering, or rule-based thresholding — each must be justified.

5 · Gephi metrics require validation

Betweenness centrality and modularity reveal structural patterns but should be validated against well-known plays before being applied to less familiar works. The metrics reveal structure; dramatic interpretation still requires human judgement.
